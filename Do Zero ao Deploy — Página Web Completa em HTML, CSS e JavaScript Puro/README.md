# Do Zero ao Deploy — Página Web Completa em HTML, CSS e JavaScript Puro

## Overview
This project is a complete web page built using pure HTML, CSS, and JavaScript. It serves as a practical example for learning web development from scratch to deployment. The project includes a responsive layout, interactive elements, and a clean design.

## Project Structure
```
Do Zero ao Deploy — Página Web Completa em HTML, CSS e JavaScript Puro
├── src
│   ├── index.html
│   ├── css
│   │   └── style.css
│   └── js
│       └── script.js
├── .gitignore
└── README.md
```

## Files Description
- **src/index.html**: The main HTML file containing the structure of the webpage, including a header, main content area with cards, and a footer.
- **src/css/style.css**: The stylesheet that provides styling for the HTML structure, ensuring a modern and responsive design.
- **src/js/script.js**: The JavaScript file that adds interactivity to the webpage, including a mobile menu and smooth scrolling effects.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `src/index.html` file in your web browser to view the project.
3. Modify the CSS and JavaScript files as needed to customize the design and functionality.

## Additional Information
- Ensure that you have a modern web browser for the best experience.
- This project is a great starting point for beginners looking to understand the basics of web development.
