# Do Zero ao Deploy — Página Web Completa em HTML, CSS e JavaScript Puro

Este projeto é uma aplicação web estática desenvolvida utilizando HTML5, CSS3 e JavaScript puro. O objetivo é criar uma página web completa e responsiva, que pode ser utilizada como base para projetos futuros.

## Estrutura do Projeto

A estrutura do projeto é a seguinte:

```
Do Zero ao Deploy — Página Web Completa em HTML, CSS e JavaScript Puro
├── index.html
├── about.html
├── contact.html
├── css
│   ├── reset.css
│   ├── styles.css
│   └── components
│       ├── header.css
│       ├── footer.css
│       └── layout.css
├── js
│   ├── main.js
│   └── modules
│       ├── nav.js
│       └── carousel.js
├── assets
│   ├── fonts
│   └── data
├── .gitignore
├── LICENSE
└── README.md
```

## Descrição dos Arquivos

- **index.html**: O arquivo principal que serve como ponto de entrada para o site.
- **about.html**: Página que fornece informações sobre o projeto.
- **contact.html**: Página que contém um formulário de contato.
- **css/**: Diretório que contém todos os arquivos CSS, incluindo reset, estilos principais e componentes.
- **js/**: Diretório que contém os arquivos JavaScript, incluindo o arquivo principal e módulos para navegação e carrossel.
- **assets/**: Diretório para fontes e dados utilizados no projeto.
- **.gitignore**: Arquivo que especifica quais arquivos devem ser ignorados pelo controle de versão.
- **LICENSE**: Arquivo que contém informações sobre a licença do projeto.
- **README.md**: Este arquivo, que fornece documentação sobre o projeto.

## Como Usar

1. Clone o repositório ou baixe os arquivos do projeto.
2. Abra o arquivo `index.html` em um navegador para visualizar a página inicial.
3. Navegue pelas outras páginas usando os links disponíveis.

## Funcionalidades

- Design responsivo que se adapta a diferentes tamanhos de tela.
- Navegação simples entre as páginas.
- Carrossel de imagens (implementado no módulo `carousel.js`).
- Formulário de contato funcional (implementado na página `contact.html`).
